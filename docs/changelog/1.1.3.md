# SIPAKU 1.1.3

Status: released

## Added
- Modul generate jadwal otomatis dengan preferensi generate, preferensi jam, filter kelas yang diikutkan generate, dan output jadwal sesuai format cetak F4.
- Preview Output Jadwal memakai renderer yang sama dengan cetak agar tampilan preview dan hasil print konsisten.
- Export jadwal ke PDF, Excel, dan cetak F4.
- TTD Kepala Sekolah dengan QR pada output jadwal.
- Preferensi kelas paralel untuk menggabungkan beberapa kelas pada mapel/guru tertentu, misalnya Bahasa Indonesia untuk X TSM dan X DKV.
- Penanda item draft `Generate`, `Manual`, `Fixed`, `Gagal`, dan `Paralel` pada tabel edit draft.

## Changed
- Layout cetak jadwal dimaksimalkan untuk satu lembar F4 landscape, kolom jabatan dihapus, kolom nomor diperkecil, dan font tabel utama diperbesar.
- Warna sel jadwal dipaksa ikut tercetak melalui aturan `print-color-adjust`.
- Aktivasi draft jadwal kini membawa sumber item `manual` atau `generate` ke jadwal aktif.

## Fixed
- QR tanda tangan dipersingkat agar aman untuk generator QR.
- Validator jadwal tidak lagi menganggap kelas paralel sebagai bentrok guru/ruang selama grup, mapel/guru, hari, dan jamnya sama.

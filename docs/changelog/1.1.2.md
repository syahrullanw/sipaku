# SIPAKU 1.1.2

Status: released

## Added
- Badge kecil `Nonaktif` pada tampilan yang menampilkan nama siswa.
- Badge `Belum Masuk Dapodik` diperkecil agar tidak mengganggu tampilan data pokok.

## Changed
- Siswa berstatus nonaktif tetap muncul pada daftar mapel aktif, input nilai, tagihan, tabungan, pembelian, dan alur terkait siswa lainnya.
- Input nilai pengetahuan, keterampilan, TP KurMer, ringkasan KurMer, dan nilai terkait siswa lain kini menonaktifkan field untuk siswa nonaktif.
- Siswa nonaktif tetap menerima tagihan baru, tetapi pembayaran tagihan tidak dapat diselesaikan sampai status siswa kembali aktif.
- Input tabungan, pembayaran pembelian, pengeluaran tak terduga, presensi, sikap, ekskul, P5, kokurikuler, prakerin, kelulusan, UKK, prestasi, dan jabatan akademik siswa kini menolak perubahan untuk siswa nonaktif.

## Fixed
- Request manual ke endpoint nilai dan keuangan tidak lagi dapat mengubah data siswa nonaktif.
- Sinkronisasi data massal tidak lagi menghapus data lama siswa nonaktif saat form disimpan oleh pengguna.

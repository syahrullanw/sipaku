# SIPAKU 1.1.1

Status: released

## Added
- Halaman khusus untuk melihat siswa pindahan yang sudah diinputkan.
- Halaman profil siswa terpusat agar admin dan wali kelas dapat melihat identitas, kelas, status Dapodik, kelengkapan data fisik, foto, dokumen fisik, dan riwayat akademik dalam satu tampilan.
- Halaman edit data siswa khusus agar proses ubah data siswa lebih fokus dan tidak bercampur dengan daftar siswa.
- Halaman tindakan massal untuk upload foto siswa.
- Badge khusus `Belum Masuk Dapodik` untuk siswa yang belum masuk Dapodik pada tampilan yang menampilkan nama siswa, kecuali absensi manual.
- Halaman profil guru untuk admin berisi data guru dan semua riwayat mengajar pada semester lampau.
- Halaman `Profil Saya` untuk guru agar guru dapat melihat data profil dan riwayat mengajar sendiri.
- Halaman `Profil Saya` untuk siswa berisi ringkasan data pribadi, kelengkapan data, dan riwayat akademik siswa tersebut.

## Changed
- Status Dapodik default siswa pindahan kini otomatis `belum_masuk`.
- Halaman Data Siswa admin direkonstruksi agar daftar utama hanya menampilkan data siswa dan ringkasan informasi penting per siswa.
- Nama siswa pada daftar data siswa kini diarahkan ke halaman profil siswa untuk melihat dan melengkapi data yang lebih detail.
- Upload kekurangan data fisik siswa dipindahkan ke halaman profil siswa agar daftar data siswa tetap rapi.
- Informasi kelengkapan data fisik, dokumen, dan foto siswa kini ditampilkan sebagai ringkasan per siswa, bukan sebagai beberapa halaman terpisah di dalam Data Siswa.
- Menu siswa dan guru ditambahkan akses profil mandiri melalui sidebar dan dropdown akun sesuai role masing-masing.

## Fixed
- Tampilan Data Siswa tidak lagi memuat daftar panjang beserta form kelengkapan dan upload dalam satu halaman yang sama.
- Siswa pindahan tidak lagi berisiko tersimpan sebagai status Dapodik aktif secara default.

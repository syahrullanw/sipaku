# SIPAKU 1.1.7

Status: released

## Added
- Kolom pencarian siswa untuk mencari dan mencetak raport perorangan berdasarkan nama atau NISN secara live (AJAX, tanpa reload).
- Pilihan kelas menggunakan checkbox pada Parameter Cetak untuk mencetak seluruh siswa dalam kelas terpilih.
- Halaman cetak seluruh siswa per bagian (Cover, Informasi Sekolah, Biodata, Hasil Penilaian, Prestasi & Catatan, Raport Lengkap) melalui route `/raport/cetak/kelas/{section}`.
- View baru `class-print.php` untuk me-render section raport seluruh siswa dalam satu kelas.

## Changed
- Dropdown siswa dihapus dari Parameter Cetak. Pencarian siswa dilakukan melalui kolom pencarian di panel terpisah.
- Tombol "Cetak Nilai Seluruh Siswa" dihapus. Digantikan dengan grup tombol "Cetak Kelas Terpilih" yang muncul setelah kelas dicentang.
- Grup tombol cetak kelas menampilkan semua section (Cover, Informasi Sekolah, Biodata, Hasil Penilaian, Prestasi & Catatan, Raport Lengkap) dalam grid 2 kolom.
- Kelas yang ditampilkan pada checkbox hanya kelas dari tahun ajaran aktif (tidak lagi menampilkan kelas dari tahun sebelumnya).
- Header "Rekap Raport - Hasil Penilaian" pada cetak raport kelas dihilangkan.

## Fixed
- Duplikasi data kelas pada daftar kelas di Parameter Cetak akibat tidak difilter tahun ajaran aktif.
- Field `siswa_id` tidak otomatis dipilih (fallback ke siswa pertama) ketika tidak ada parameter di URL, mengurangi query yang tidak perlu.

# SIPAKU 1.1.0

Status: in development

## Added
- Template import siswa kini dapat digenerate langsung oleh sistem agar format kolom selalu sesuai dengan format yang diterima aplikasi.
- Sheet keterangan pada template import siswa untuk menjelaskan format data spesifik, termasuk jenis kelamin, tanggal lahir, NISN, NIPD, status siswa, dan format lain yang dipakai sistem.
- Halaman khusus `Siswa Pindahan` untuk input siswa pindahan dari sekolah lain.
- Akses menu `Siswa Pindahan` untuk user tata usaha.
- Generator NIPD otomatis berbasis tahun ajaran dan tipe siswa, misalnya `25261001` untuk siswa reguler dan `25262001` untuk siswa pindahan.
- Menu admin `User Rules` untuk mengatur hak akses semua jenis user terhadap modul-modul aplikasi.
- Matrix hak akses module per role untuk `admin`, `staff`, `guru`, `wali_kelas`, `siswa`, `bendahara`, `kepala_sekolah`, `tata_usaha`, `waka_kurikulum`, dan `kepala_prodi`.
- Guard akses URL langsung berdasarkan User Rules, sehingga module yang disembunyikan dari menu juga tidak bisa dibuka lewat URL manual.
- Migrasi referensi `20260522130000_create_user_module_rules.sql` untuk skema penyimpanan rule module per role.
- Modul Tata Usaha `Cetak Absensi Manual` untuk membuat lembar presensi siswa universal per kelas atau per mata pelajaran.
- Cetak absensi manual ukuran F4/Folio dengan kolom tanggal 1-31, rekap S/I/A, kolom keterangan, dan tanda tangan.
- Sampul/cover presensi manual berisi logo, identitas sekolah, kelas/rombel, tahun ajaran, dan garis tepi dekoratif.
- Pilihan jenis presensi `Presensi Kelas` dan `Presensi Mapel` pada cetak absensi manual.
- Presensi kelas dapat mencetak beberapa kelas sekaligus selama masih dalam satu tingkat yang sama.
- Presensi mapel dapat mencetak satu rombel berdasarkan mata pelajaran dan guru pengampu yang terhubung ke kelas tersebut.
- Template siap pakai pada Persuratan untuk `Surat Keterangan Aktif Belajar`, `Surat Penerimaan Siswa Pindahan`, `Surat Peringatan Siswa`, `Surat Pemberitahuan Kegiatan`, dan `Surat Mutasi / Pindah Siswa`.
- Jenis surat keluar spesifik untuk lima template sekolah yang sering digunakan, lengkap dengan kode nomor surat baru.

## Changed
- Menu sidebar admin kini difilter berdasarkan User Rules dan tetap mempertahankan aturan kontekstual seperti wali kelas, kepala prodi, bendahara aktif, kepala sekolah, dan penanggung jawab PPDB.
- Modul Wali Kelas kini memakai role efektif `wali_kelas`, bukan role dasar `guru`, sehingga guru non-wali kelas tidak otomatis mendapat akses.
- Item laporan umum tidak lagi membuat group sidebar Wali Kelas muncul untuk guru non-wali kelas.
- Import siswa tidak lagi bergantung pada template manual yang rawan salah format.
- NIPD siswa baru tidak perlu diisi manual saat sistem dapat membuat nomor berurutan sesuai prefix tahun ajaran dan tipe siswa.
- Akses khusus tata usaha, waka kurikulum, PPDB admin, dan manajemen pengguna dapat mengikuti grant eksplisit dari User Rules.
- Cetak presensi kelas multi-rombel kini digabung dalam satu daftar siswa dengan baris keterangan kelas dan kode rombel pada kolom `Ket.`.
- Cover presensi manual tidak lagi menampilkan keterangan bulan karena template presensi bersifat universal per bulan.
- Form surat keluar Persuratan kini memiliki dropdown `Template Siap Pakai` yang otomatis mengisi jenis surat, tujuan, perihal, lampiran, tembusan, dan isi surat namun tetap dapat diedit.

## Fixed
- Potensi bentrok NIPD antar siswa dikurangi dengan pola penomoran otomatis berbasis prefix tahun ajaran, tipe siswa, dan nomor urut.
- Guru yang bukan wali kelas tidak lagi dapat membuka modul Wali Kelas melalui URL langsung hanya karena memiliki role dasar `guru`.
- Group sidebar Wali Kelas tidak lagi tampil hanya karena user masih memiliki akses ke modul laporan umum.

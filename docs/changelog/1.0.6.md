# SIPAKU 1.0.6

Status: in development

## Added
- File Manager admin untuk melihat, memfilter, dan mengunduh file terindeks.
- Struktur penyimpanan arsip per tahun ajaran, semester, kategori, dan subkategori.
- Indeks database `file_manager_items` untuk pencarian file terpusat.
- Maintenance Mode admin untuk menutup akses publik dan pengguna non-admin, sementara admin tetap dapat login dan menguji aplikasi.
- Mode presensi siswa `Guru Pengganti` agar guru dapat membuat presensi pada jadwal guru lain dengan catatan wajib.
- Metadata sesi presensi `guru_jadwal_id`, `tipe_sesi`, dan `catatan_pengganti` untuk membedakan sesi sesuai jadwal dan sesi pengganti.
- Tab `Input Nilai` dan `Master UKK` pada menu Kaprodi `UKK & Skill Passport` agar pekerjaan input nilai terpisah dari pengaturan paket, SKKNI, DUDI, dan asesor.
- Pengaturan `Titimangsa Cetak` oleh kepala prodi untuk sertifikat UKK dan skill passport satu kelas.
- Tombol cetak terpisah untuk `Cetak Sertifikat Depan`, `Cetak Lembar Belakang`, dan `Cetak Skill Passport Kelas`.
- Daftar asesor pada tab master UKK lengkap dengan aksi ubah dan hapus.

## Changed
- Upload foto siswa, dokumen fisik siswa, asset profil sekolah, kop surat, PDF persuratan, dan beberapa lampiran keuangan mulai diarahkan ke storage arsip terstruktur.
- File lama tetap dipertahankan sebagai arsip `legacy` agar path lama tidak rusak.
- Login non-admin otomatis ditolak saat Maintenance Mode aktif dan diarahkan ke halaman maintenance.
- Rekap presensi guru dan rekap bendahara menampilkan penanda `Sesuai Jadwal` atau `Guru Pengganti` beserta catatan pengganti.
- Tampilan menu `UKK & Skill Passport` dibuat lebih rapi dengan header filter, ringkasan jumlah data, dan pemisahan visual antara input nilai dan master data.
- Nilai akhir UKK dihitung otomatis dari bobot teori 40% dan praktik 60%, serta kolom nilai akhir pada form dibuat readonly.
- Titimangsa sertifikat UKK dan skill passport memakai format tanggal panjang Indonesia, contoh `02 Januari 2026`.
- Cetak sertifikat UKK kelas hanya mencetak lembar depan per siswa, sedangkan lembar belakang dicetak melalui tombol tersendiri karena isinya sama untuk satu kelas.
- DUDI penguji pada input nilai UKK otomatis terisi dari data penilaian yang sudah tersimpan.
- Tampilan cetak surat keluar pada menu Persuratan disesuaikan agar kop surat dan badan surat sejajar.

## Fixed
- Nilai akhir UKK tidak lagi tersimpan `0` saat nilai teori dan praktik sudah diisi.
- Input nilai kosong pada UKK tidak lagi dibaca sebagai angka `0`.
- Skill passport tidak lagi memakai tanggal hari ini otomatis ketika titimangsa belum diatur oleh kepala prodi.
- Aksi tambah, ubah, dan hapus master UKK tetap kembali ke tab `Master UKK` setelah diproses.

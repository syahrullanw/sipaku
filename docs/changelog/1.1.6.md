# SIPAKU 1.1.6

Status: released

## Added
- Tombol "Ajukan TTD Semua Siswa" pada halaman Transkrip untuk mengajukan tanda tangan digital semua siswa dalam satu kelas sekaligus.
- Tombol "Cetak Semua Transkrip" untuk mencetak transkrip seluruh siswa dalam satu kelas (masing-masing halaman F4).
- Waktu pengajuan (`created_at`) dan waktu disetujui (`approved_at`) pada detail status TTD Digital.
- Halaman cetak massal `print-all.php` dengan pemisah halaman per siswa.
- Catatan deploy `README_UPLOAD.txt` pada paket update 1.1.6.

## Changed
- Halaman Cetak Raport dan Laporan Tengah Semester: field pilihan "Semester" dihapus. Semester sekarang otomatis mengikuti tahun ajaran semester aktif, bukan dari masing-masing kelas.
- Dropdown kelas pada Cetak Raport dan Laporan Tengah Semester: hanya menampilkan tingkat dan nama kelas (tanpa tahun ajaran).
- Card "Cetak Transkrip" dipisah menjadi "Cetak Transkrip Siswa" (per siswa) dan "Aksi Kelas" (cetak semua / ajukan TTD semua) agar lebih jelas.
- Tampilan card aksi dilengkapi ikon, jumlah siswa, dan nama kelas.
- Badge status TTD Digital menggunakan warna berbeda: abu (missing/inactive), kuning (pending), hijau (approved), merah (revoked).
- Label tombol "Ajukan TTD Digital" berubah menjadi "Sudah Diajukan / Disetujui" dan tombol dinonaktifkan ketika status pending atau approved.

## Fixed
- Tombol "Ajukan TTD Digital" kini menjadi tidak aktif (disabled) ketika pengajuan sudah dikirim (pending) atau sudah disetujui (approved).
- Logika `canRequest` pada `summarizeDigitalSignature()` diperbaiki: hanya bernilai `true` ketika status `revoked` atau belum ada pengajuan.
- Error `ValueError: Invalid or uninitialized Zip object` pada UpdateController saat upload ZIP — ditambahkan flag `$zipOpened` dan null-safe close.
- File tidak terekstrak dengan benar saat ZIP memiliki root directory prefix (misal `sipaku-1.1.7/`). Sekarang menggunakan `extractTo()` + `findUpdateRoot()` untuk deteksi otomatis root direktori update.
- Perubahan file PHP tidak langsung terlihat setelah update karena opcache. Ditambahkan `opcache_reset()` setelah ekstraksi.

## Added
- Halaman Update Aplikasi (`/admin/update`) untuk melakukan pembaruan langsung melalui UI admin dengan upload file ZIP.
- Backup otomatis file yang akan ditimpa ke `storage/backups/updates/` sebelum ekstraksi.
- Eksekusi SQL migration: jika ZIP berisi `database/migration.sql`, sistem akan membackup database lalu mengeksekusi pernyataan SQL tersebut.
- Backup database otomatis (SQL dump) sebelum menjalankan migration.
- Validasi file ZIP: pemeriksaan MIME type, ekstensi, ukuran, dan keberadaan file VERSION di root ZIP.
- Riwayat paket update yang tersimpan di direktori `update/` ditampilkan di halaman update.
- Panduan update (`docs/panduan-update.md`) berisi aturan pembuatan paket update dan konvensi SQL migration.

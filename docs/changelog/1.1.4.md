# SIPAKU 1.1.4

Status: released

## Added
- Field nomor ijazah dan jenis kekhususan pada input status kelulusan siswa kelas 12 yang dinyatakan lulus.
- Pilihan cakupan cetak transkrip nilai: kelas 10-12 atau kelas 12 saja.
- Migrasi `20260608100000_add_graduation_transcript_fields.sql` untuk menambah kolom data transkrip kelulusan.
- Migrasi `20260608110000_add_transcript_number_prefix.sql` untuk menambah kolom prefix nomor transkrip.
- Migrasi `20260608120000_move_skl_transcript_settings_to_school_year.sql` untuk menambahkan pengaturan SKL dan transkrip per tahun ajaran tanpa menghapus data lama di profil sekolah.
- Migrasi `20260608130000_expand_transcript_prefix_length.sql` untuk memperluas panjang custom prefix nomor transkrip.

## Changed
- Format cetak transkrip nilai diperbarui mengikuti format resmi dengan kop satuan pendidikan, identitas siswa, tabel mata pelajaran dan nilai, serta tanda tangan kepala sekolah.
- Kop surat transkrip disesuaikan agar memenuhi lebar area isi dokumen.
- Label tanda tangan transkrip diubah menjadi Kepala Sekolah.
- Pengaturan nomor SKL, tanggal rapat pleno, titimangsa SKL, dan prefix nomor transkrip dipindahkan dari Master Sekolah ke Master Tahun Ajaran.
- Cetak SKL dan transkrip membaca pengaturan dari tahun ajaran dokumen/kelas, sehingga bisa berbeda antar tahun ajaran.
- Default nomor transkrip saat custom prefix dikosongkan menjadi `Nomor Urut/Kode Sekolah/Kode Bidang/Bulan/Tahun`.
- Transkrip nilai dibatasi untuk kelas 12 dan hanya menampilkan mata pelajaran aktif yang terhubung ke kelas tersebut.
- Nilai pada transkrip dicetak dengan format dua desimal dan menampilkan baris rata-rata nilai.
- Baris kosong setelah rata-rata nilai pada tabel transkrip dihapus.
- Border luar halaman transkrip dihapus dan layout cetak dimaksimalkan untuk kertas F4.

## Fixed
- Nama mata pelajaran pada transkrip tidak lagi menampilkan suffix kelas.
- Garis tambahan di bawah kop transkrip dihapus.
- Garis/titik ganda pada bagian NIP tanda tangan transkrip dihilangkan.

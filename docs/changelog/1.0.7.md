# SIPAKU 1.0.7

Status: in development

## Added
- Menu `Salin Data Periodik` kini ikut menyalin `Jadwal Pelajaran` beserta ringkasan jumlah data sumber dan semester aktif.
- Tombol `Salin Jadwal` pada halaman `Jadwal Pelajaran` untuk menyalin jadwal dari tahun ajaran sumber saat tahun tujuan belum memiliki jadwal.
- Login siswa mendukung kombinasi NIS sebagai username dan NIS sebagai password.
- Menu siswa `Data Diri Saya` agar siswa dapat memperbarui detail biodata dengan form yang sama seperti edit siswa wali kelas.
- Menu siswa `Berkas Fisik` agar siswa dapat mengupload dan merevisi dokumen fisik secara mandiri.
- Upload foto mandiri pada menu siswa `Data Diri Saya`, memakai penyimpanan foto siswa yang sama dengan admin/wali kelas.
- Indikator progres upload/loading global dengan animasi persentase, termasuk progres upload file berbasis browser.

## Changed
- Akun siswa baru dan reset password siswa kini memprioritaskan NIS/NIPD sebagai username dan password awal, dengan NISN tetap menjadi fallback jika NIS tidak tersedia.
- Tombol `Salin Jadwal` otomatis nonaktif saat jadwal tahun ajaran terpilih sudah tersedia atau tidak ada sumber jadwal.
- Halaman berkas fisik siswa menampilkan penanda dokumen lengkap/belum lengkap serta persentase kelengkapan dokumen.

## Fixed
- Akun siswa lama yang masih memakai username berbeda tetap dapat login menggunakan NIS + password NIS selama data NIS cocok dengan siswa aktif.

## Notes
- Tambahkan fitur baru versi 1.0.7 di file ini selama status masih `in development`.
- Ubah status menjadi `released` saat versi siap dipakai di production.

# SIPAKU 1.1.5

Status: released

## Added
- Menu Bantuan `Pedoman` untuk semua user login, berisi panduan penggunaan modul sesuai role dan hak akses user.
- Menu Bantuan `Changelog` untuk melihat riwayat pembaruan aplikasi per versi langsung dari sistem.
- Katalog pedoman modul untuk admin, guru, siswa, wali kelas, bendahara, kepala sekolah, tata usaha, waka kurikulum, kepala prodi, PPDB, dan keuangan.
- Tombol hapus pendaftar PPDB pada daftar pendaftar admin dan guru penanggung jawab.
- Catatan deploy `README_UPLOAD.txt` pada paket bug fix PPDB.

## Changed
- Sidebar mendapat grup `Bantuan` agar user mudah menemukan panduan dan riwayat pembaruan.
- Halaman pedoman otomatis menampilkan modul yang relevan berdasarkan hak akses efektif user.

## Fixed
- Pendaftaran PPDB tidak lagi gagal dengan error `Call to undefined method App\Models\PpdbRegistrant::sequenceNumberInPeriod()`.
- Refresh browser setelah submit pendaftaran PPDB tidak lagi dipicu oleh fatal error setelah data tersimpan.
- Data pendaftar PPDB dobel kini dapat dibersihkan dari aplikasi melalui tombol hapus.
